## 1. Обзор продукта

### 1.1 Что это?

**asystem.ai** — веб-платформа для IT-компании asystem, которая решает три задачи:

1. **Привлечение клиентов** — лендинг с квиз-формой заявки на IT-услуги
2. **Управление партнёрами** — раздел партнёрской программы с условиями и онбордингом
3. **Витрина продуктов** — каталог готовых решений и интеграций (Phase 2+)

Платформа включает личные кабинеты (клиент, партнёр, админ), Telegram-бот для оперативного управления заявками и мультиязычность (RU/KG/EN).

### 1.2 Почему это нужно?

| Проблема | Решение |
|----------|---------|
| Заявки приходят хаотично (чаты, звонки, сарафан) | Единая система приёма и трекинга заявок |
| Нет прозрачности для клиента — «а что с моим проектом?» | Личный кабинет с отслеживанием статуса |
| Партнёры работают неформально | Структурированная партнёрская программа |
| Менеджер должен сидеть за панелью 24/7 | Telegram-бот с уведомлениями и быстрыми действиями |
| Нет единой точки входа для всех сегментов | Сайт с role-based entry points |

### 1.3 Видение

> Клиент заходит на asystem.ai → за 2 минуты оставляет заявку → получает подтверждение → отслеживает проект в кабинете. Менеджер получает push в Telegram → реагирует в один тап. Партнёр видит своих клиентов и статусы.

## 2. Целевая аудитория

### 2.1 Сегменты

#### 🚀 Клиент (Client)
- **Кто:** Владелец бизнеса (малый/средний/крупный) в Кыргызстане и СНГ
- **Потребность:** Нужен сайт, бот, приложение или автоматизация процессов
- **Боль:** Не знает с чего начать, боится переплатить, хочет понимать сроки
- **Путь:** Главная → «Мне нужен проект» → Квиз → Заявка → Кабинет

#### 🤝 Партнёр (Partner)
- **Кто:** Предприниматель, блогер, консультант с аудиторией — известные люди в своих сферах
- **Потребность:** Зарабатывать на рекомендациях IT-услуг своим клиентам
- **Боль:** Нет прозрачности по статусам клиентов и комиссиям
- **Путь:** Главная → «Я партнёр» → Условия → Заявка на партнёрство → Кабинет

#### ⚡ Пользователь продуктов (Product User)
- **Кто:** Бизнес, ищущий готовые решения
- **Потребность:** Быстро внедрить готовый продукт без кастомной разработки
- **Путь:** Главная → «Ваши продукты» → Каталог → Демо/Покупка
- **Статус:** Phase 2+ (coming soon на MVP)

## 4. Функциональные требования

### 4.1 Публичный сайт

#### FR-001: Splash Screen (Главная)
- **Описание:** Полноэкранная страница с 3 glass-morphism карточками
- **Карточки:** «Я партнёр» / «Мне нужен проект» / «Ваши продукты»
- **Фон:** Анимированные частицы (particles) в синих тонах
- **Текст:** «Что привело вас к нам?»
- **Поведение:** По клику — плавный переход на соответствующий раздел
- **Приоритет:** P0 (Must Have)

#### FR-002: Клиентский лендинг (/client)
- **Hero-секция:** Заголовок + подзаголовок + CTA «Оставить заявку»
- **Секция услуг:** 4 карточки с описанием (сайты, боты, приложения, системы)
- **Секция кейсов:** Карусель/сетка выполненных проектов (фото + описание + результат)
- **Секция «Как мы работаем»:** 4 шага (Заявка → Обсуждение → Разработка → Запуск)
- **CTA-блок:** Повторный призыв к действию
- **Приоритет:** P0

#### FR-003: Квиз-форма заявки (/client/request)
- **Шаг 1:** Тип услуги (radio cards): Сайт / Бот / Приложение / Автоматизация / Другое
- **Шаг 2:** Детали (зависят от типа):
  - Сайт: тип (лендинг/корпоративный/e-commerce), есть ли дизайн, примеры
  - Бот: платформа (Telegram/WhatsApp/другой), функционал
  - Приложение: платформы (iOS/Android/обе), основные функции
  - Автоматизация: какой процесс, текущие инструменты
- **Шаг 3:** Сроки (ASAP / 1-2 недели / месяц / не срочно)
- **Шаг 4:** Бюджет (до 30K / 30-100K / 100-500K / 500K+ KGS / «Не определён»)
- **Шаг 5:** Контакты (имя, компания, телефон, email, предпочтительный способ связи)
- **Прогресс-бар:** визуальный индикатор шагов
- **Приоритет:** P0

#### FR-004: Партнёрский лендинг (/partner)
- **Hero:** «Зарабатывайте вместе с asystem»
- **Секция бенефитов:** Комиссия, поддержка, маркетинговые материалы
- **Секция «Как это работает»:** 3 шага (Регистрация → Рекомендация → Заработок)
- **Форма заявки на партнёрство:** Имя, сфера деятельности, аудитория, контакты
- **Приоритет:** P0

#### FR-005: Продукты (/products) — Coming Soon
- **Описание:** Красивая заглушка с тизер-карточками (blur-эффект)
- **CTA:** «Уведомить о запуске» → сбор email
- **Приоритет:** P1

#### FR-006: Мультиязычность (i18n)
- **Языки:** Русский (по умолчанию), Кыргызский, English
- **Переключатель:** В навигации, флаги + код языка
- **Роутинг:** Prefix-based (/ru, /kg, /en)
- **Приоритет:** P0

### 4.2 Личные кабинеты

#### FR-007: Аутентификация
- **Методы:** Email + пароль, Google OAuth, Telegram Login Widget
- **Роли:** client, partner, admin
- **Регистрация:** При первой заявке автоматически создаётся аккаунт
- **Приоритет:** P0

#### FR-008: Кабинет клиента (/client/dashboard)
- **Мои заявки:** Список с фильтрами по статусу
- **Детали заявки:** Статус (новая → в обсуждении → в работе → на проверке → завершена)
- **Документы:** Загрузка/скачивание файлов по проекту
- **Уведомления:** Email + in-app при смене статуса
- **Приоритет:** P1

#### FR-009: Кабинет партнёра (/partner/dashboard)
- **Мои клиенты:** Список приведённых клиентов
- **Статусы проектов:** Отслеживание прогресса
- **Реферальная ссылка:** Уникальная ссылка для отслеживания
- **Комиссии:** История начислений и выплат
- **Приоритет:** P1

#### FR-010: Админ-панель (/admin)
- **Pipeline:** Kanban-доска заявок (Новые → В обсуждении → В работе → Готово)
- **Drag & Drop:** Перетаскивание карточек между колонками
- **Детали заявки:** Полная информация + история коммуникаций
- **Управление клиентами:** CRUD, поиск, фильтры
- **Управление партнёрами:** Список, статистика, комиссии
- **Приоритет:** P1

### 4.3 Интеграции

#### FR-011: Telegram Bot
- **Уведомления:**
  - Новая заявка → push с деталями
  - Смена статуса → push партнёру/клиенту (если подключил бот)
- **Быстрые действия из бота:**
  - «✅ Принять» — перевести заявку в «В обсуждении»
  - «📞 Позвонить» — показать контакт клиента
  - «💬 Ответить» — отправить сообщение клиенту
- **Команды:**
  - /start — подключение аккаунта
  - /status — текущие заявки
  - /stats — статистика за период
- **Приоритет:** P0 (уведомления), P1 (быстрые действия)

#### FR-012: Email-уведомления
- **Триггеры:** Подтверждение заявки, смена статуса, приглашение в кабинет
- **Шаблоны:** Брендированные, на языке пользователя
- **Сервис:** Resend
- **Приоритет:** P1

## 5. Нефункциональные требования

### 5.1 Производительность
- **Lighthouse Score:** ≥ 90 (Performance, Accessibility, SEO)
- **FCP:** < 1.5s
- **LCP:** < 2.5s
- **TTI:** < 3.5s
- **Core Web Vitals:** Все в зелёной зоне

### 5.2 Безопасность
- HTTPS обязательно
- CSRF-защита на всех формах
- Rate limiting на API (заявки: 5/мин с одного IP)
- Валидация на клиенте и сервере
- Sanitization всех input-полей
- Row Level Security (Supabase RLS) для разделения данных

### 5.3 SEO
- SSR/SSG для публичных страниц
- Meta-теги, Open Graph, Twitter Cards
- Structured Data (Organization, LocalBusiness)
- Sitemap.xml + robots.txt
- Hreflang для мультиязычности

### 5.4 Доступность (a11y)
- WCAG 2.1 Level AA
- Семантический HTML
- ARIA-атрибуты
- Keyboard navigation
- Контрастность текста ≥ 4.5:1

### 5.5 Аналитика
- Google Analytics 4
- Яндекс.Метрика (основной трафик из СНГ)
- UTM-разметка для партнёрских ссылок
- Трекинг воронки: Визит → Выбор роли → Заявка → Регистрация

## 10. Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Мало трафика на старте | Высокая | Высокое | Партнёры = основной канал, SEO с первого дня |
| Квиз слишком длинный | Средняя | Высокое | A/B тест 3-шаговый vs 5-шаговый |
| Кыргызский перевод низкого качества | Средняя | Среднее | Нативный переводчик, не машинный перевод |
