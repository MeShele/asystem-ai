
### 3.2 Кнопки

| Вариант | Использование | Стиль |
|---------|---------------|-------|
| **Primary** | CTA, главные действия | Gradient fill, white text, glow shadow |
| **Secondary** | Второстепенные действия | Border only, transparent bg |
| **Ghost** | Ссылки, навигация | No border, text only |
| **Sizes** | sm / md / lg | 8-12px / 12-14px / 16px padding |

### 3.3 Формы

| Элемент | Стиль |
|---------|-------|
| **Input** | bg-secondary, border, rounded-[10px], focus: blue border + 3px ring |
| **Select** | Кастомный, как Input |
| **Radio Cards** | Glass card стиль, border-brand-500 при выборе |
| **Progress** | Gradient bar, animated fill |

### 3.4 Статус-бейджи

| Статус | Цвет | Label (RU) |
|--------|------|------------|
| `new` | Blue | Новая |
| `discussing` | Cyan | Обсуждение |
| `in_progress` | Yellow | В работе |
| `review` | Purple | На проверке |
| `completed` | Green | Завершена |
| `cancelled` | Red | Отменена |

## 5. Анимации

### 5.1 Принципы

| Принцип | Реализация |
|---------|------------|
| **Функциональность** | Анимация помогает, не отвлекает |
| **Easing** | `cubic-bezier(0.16, 1, 0.3, 1)` — пружинистый |
| **Длительность** | 200-500ms для UI, 800ms для появления |
| **Parallax** | Только на hero, subtle |

### 5.2 Каталог анимаций

| Элемент | Тип | Описание |
|---------|-----|----------|
| Particles BG | Canvas loop | Синие частицы + линии связей |
| Entry Cards | Hover lift | translateY(-12px) + glow |
| Section reveal | Scroll trigger | fadeInUp при входе в viewport |
| Buttons | Hover scale | translateY(-2px) + shadow increase |
| Cards | Hover glow | Border color + box-shadow |
| Page transition | Cross-fade | 300ms opacity transition |
| Quiz steps | Slide | slideLeft/slideRight between steps |
| Kanban drag | Lift + shadow | Scale 1.02 + elevated shadow |
